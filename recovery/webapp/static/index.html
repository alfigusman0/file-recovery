Flashdisk & memori

Untuk USB, kartu memori, dan perangkat yang RAW atau tidak terbaca. Urutan aman: diagnosa, salin, pulihkan, lalu perbaiki.

1. Diagnosa
Membaca boot sector dan mengenali sistem file.
2. Uji permukaan
Membaca semua sektor. Tidak menulis.
3. Salin ke image
Cadangan sebelum perbaikan apa pun.
4. Pulihkan dari image
Carving dari file cadangan.

Cek sistem file (aman)

Hanya memeriksa, tidak mengubah data. Windows: chkdsk tanpa /f. Linux: fsck -n. macOS: verifyVolume.

5. Perbaiki sistem file menulis

Menulis ke perangkat. Salin ke image dulu. Perangkat sistem tidak akan diperbaiki.

Uji kapasitas menulis file uji

Mendeteksi flashdisk palsu: menulis data uji ke drive atau folder, lalu membacanya kembali dan memeriksa isinya. Pastikan ruang kosong cukup. File yang sudah ada tidak diubah.
